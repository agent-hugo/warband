# Warband

Кооперативный колодострой для 3 игроков, каждый со своего телефона. Правила и устройство — в [DESIGN.md](DESIGN.md).

Играть: https://agent-hugo.github.io/warband/

```sh
npm install
npm run dev          # http://<адрес>:5173
npm test             # движок
npm run typecheck
```

Сеть идёт через MQTT-брокер (по умолчанию `wss://mqtt.flespi.io`). Токен вводится на главной странице
или приходит в ссылке-приглашении (`#r=КОД&t=ТОКЕН`) и хранится только в браузере.

- `#host=КОД` — хост-страница: считает игру, показывает поле и QR-код для игроков.
- `#r=КОД` — экран игрока.
- `#local` — все герои на одном экране, без сети.

Хост без браузера и проверка сети через брокер:

```sh
MQTT_TOKEN=... npm run host -- КОД
MQTT_TOKEN=... npm run net-smoke
```
