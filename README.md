# Warband

Прототип игры в реальном времени для нескольких телефонов: каждый игрок водит своего человечка по общей
карте экранным джойстиком. Проверка связки **MQTT + WebRTC** для живой игры.

Играть: [agent-hugo.github.io/warband](https://agent-hugo.github.io/warband/)

(Прежняя пошаговая карточная версия — тег `cards-v1`.)

## Как устроено

- **Хост** считает мир 30 раз в секунду и рассылает снимки. Хост — либо телефон одного из игроков
  (выбирается сам, если хоста нет), либо хост-страница на ноутбуке (`#host=КОД`), которая перехватывает комнату.
  Побеждает самый новый хост; телефон-хост, погасив экран, отдаёт комнату.
- **MQTT-брокер** (`warband/r/<КОД>/…`): кто хост (`host`, retained + last will), кто в комнате (`p/<id>`),
  обмен WebRTC-описаниями (`sig/<кому>/<от кого>`), позиции для следующего хоста (`pos`), и запасной канал
  игры (`up/<id>`, `dn`) — 10 сообщений в секунду, пока у игрока нет прямого соединения.
- **WebRTC DataChannel** без гарантии доставки и порядка: ввод от игрока и снимки от хоста идут напрямую,
  30 раз в секунду. STUN — публичный Google; TURN можно указать на главной в «Дополнительно».
- **Предсказание**: свой человечек двигается сразу, а когда приходит позиция от хоста, ещё не учтённый
  хостом ввод проигрывается поверх неё. Чужие рисуются чуть в прошлом, между двумя снимками.
  В меню игрока это можно выключить, чтобы почувствовать задержку, и переключиться на «только брокер».

```sh
npm install
npm run dev          # http://<адрес>:5173
npm test
MQTT_TOKEN=... npm run net-smoke   # хост и два игрока через брокер
```

Токен брокера вводится на главной или приходит в ссылке-приглашении (`#i=…`, base64url: не шифрование)
и хранится только в браузере.
